1. Desain Interface & Template (Frontend)

1.1 Latar Belakang & Analisis Kebutuhan

Yayasan Gerakan Nasional Orang Tua Asuh (GNOTA) merupakan lembaga nirlaba independen terakreditasi Kemensos RI yang berfokus membantu anak-anak usia sekolah dari keluarga prasejahtera agar tidak putus sekolah. Dalam proses donasi, donatur dapat berperan sebagai Orang Tua Asuh yang membiayai paket perlengkapan sekolah berupa baju seragam lengkap, sepatu, tas ransel, dan perlengkapan alat tulis bagi siswa SD, SMP, maupun SMA/SMK.

Proyek ini merevitalisasi dan memodernisasi antarmuka web GNOTA (http://www.gnota.or.id/beri-donasi/) ke dalam sistem Single Page Application (SPA) yang interaktif, memiliki navigasi modular, responsif terhadap seluruh perangkat, dan mengintegrasikan dua portal utama: Portal Donatur Publik dan Dashboard Staf Yayasan.

1.2 Alur Antarmuka Pengguna (UI/UX User Flow)

Alur penggunaan dirancang seringkas dan sejelas mungkin untuk meminimalkan beban kognitif donatur dan staf:

  • Alur Donatur: Eksplorasi Capaian Nasional → Pemilihan Paket Pendidikan (SD/SMP/SMA) → Pemilihan Anak Asuh (Otomatis oleh sistem atau Memilih dari Galeri) → Pengisian Identitas & Pesan Doa → Simulasi Pembayaran (QRIS / Virtual Account) → Penerbitan Kuitansi Resmi Sah GNOTA.
  • Alur Staf Yayasan: Akses Dashboard → Monitoring Indikator Kinerja Utama (KPI) → Pencatatan Transaksi Donasi Masuk & Verifikasi Status → Pengelolaan Target Program Pendidikan → Manajemen Relasi Donatur/Ortu Asuh dengan Siswa → Ekspor Laporan CSV.

1.3 Sistem Desain, Skema Warna & Tipografi

Desain mengedepankan identitas visual terpercaya dan ramah anak:

  • Primary Blue #0070cc / #0059a4: Identitas resmi GNOTA, mencerminkan kepercayaan, integritas, dan perlindungan anak.
  • Accent Amber #f59e0b / #fbbf24: Warna keceriaan anak-anak, masa depan cerah, dan harapan pendidikan.
  • Success Green #10b981: Indikator transaksi terverifikasi dan paket bantuan yang telah tersalurkan.
  • Tipografi: Menggunakan Plus Jakarta Sans untuk memberikan kesan modern, bersih, dan memiliki tingkat keterbacaan tinggi di berbagai resolusi layar.
  • Ikonografi: Menggunakan Lucide React Icons yang seragam dan ringan.

1.4 Fitur & Tampilan Portal Donatur Publik

  • Live Tracker Target Nasional: Menampilkan total donasi terkumpul, target tahunan, serta progress bar visual persentase capaian secara real-time.
  • Katalog Paket Donasi (Format Asli GNOTA):
    • SD: Paket 1 (Rp 250.000 / 1 thn), Paket 2 (Rp 750.000 / 3 thn), Paket 3 (Rp 1.500.000 / 6 thn penuh).
    • SMP: Paket 1 (Rp 300.000 / 1 thn), Paket 2 (Rp 900.000 / 3 thn).
    • SMA/SMK & Bantuan Pelosok 3T: Paket pendampingan vokasi dan daerah terpencil.
  • Direktori Calon Anak Asuh: Kartu profil siswa lengkap dengan foto, sekolah, daerah asal (Cilacap, Pandeglang, Kupang NTT, dll.), kebutuhan perlengkapan sekolah, dan tombol "Jadikan Anak Asuh Saya".
  • Wizard Donasi 5 Langkah: Alur bertahap yang membimbing calon donatur hingga terbit invoice.
  • Kuitansi Resmi Sah Digital: Dilengkapi kop surat resmi yayasan, stempel digital, nomor kuitansi unik, dan tombol cetak dokumen siap PDF (window.print()).

1.5 Fitur & Tampilan Dashboard Staf Yayasan

  • Ringkasan & KPI (#/dashboard/overview): 5 kartu metrik utama (Donasi Masuk, Target Tahunan, Donatur, Penerima Bantuan, dan Karyawan) serta diagram capaian program.
  • Pencatatan Donasi (#/dashboard/donations): Tabel riwayat transaksi donasi, filter status (Menunggu Verifikasi, Terverifikasi, Disalurkan), tombol verifikasi kilat, pencatatan donasi manual kantor, dan fitur ekspor data ke CSV.
  • Target Program (#/dashboard/targets): Perhitungan sisa dana yang dibutuhkan serta fitur inline-edit target dana per jenjang.
  • Donatur & Ortu Asuh (#/dashboard/donaturs): Database donatur, kategori (Individu vs CSR), dan relasi anak asuh yang dibiayai.
  • Penerima Donasi (#/dashboard/anak-asuh): Database siswa binaan penerima manfaat dan formulir tambah anak asuh baru.
  • Staf & Karyawan (#/dashboard/karyawan): Data tim internal yayasan beserta wilayah penugasan operasional.
  • Deep Linking & Salin Link: Setiap menu memiliki direct link URL hash dan tombol "Salin Link Halaman" dengan toast notifikasi interaktif.

5. Kesimpulan & Potensi Pengembangan

5.1 Kesimpulan

Pengembangan antarmuka front-end aplikasi donasi Yayasan GNOTA ini telah memenuhi seluruh kriteria dan spesifikasi yang ditentukan dalam instruksi Ujian Tengah Semester (UTS) Pemrograman Web:

  1. Ketentuan Teknis Terpenuhi: Dibangun menggunakan teknologi web standar (HTML5, CSS3 via Tailwind CSS, JavaScript ECMAScript modern via React 19 dan Vite 5).
  2. Kelengkapan Fitur: Mencakup seluruh entitas yang disyaratkan: pencatatan donasi multi-status, target donasi dinamis, database donatur & relasi orang tua asuh, penerima manfaat (anak asuh), serta manajemen staf yayasan.
  3. Kualitas UI/UX yang Unggul: Memiliki tampilan visual yang profesional, konsistensi warna brand GNOTA, tata letak yang bersih, komponen interaktif, umpan balik yang jelas (toast, status badge), dan kemudahan navigasi deep-link.
  4. Responsif & Adaptif: Antarmuka berjalan optimal pada desktop, tablet, maupun perangkat seluler.
  5. Ketersediaan Publik: Repositori GitHub terpublikasi dengan rapi dan live demo aktif 100% di GitHub Pages.

5.2 Potensi Pengembangan Masa Depan

Untuk pengembangan tahap produksi skala penuh berikutnya, sistem ini sangat potensial untuk ditingkatkan melalui:

  • Backend REST/GraphQL API & Database Terpusat: Integrasi dengan backend Node.js / Laravel dan database PostgreSQL untuk sinkronisasi multi-pengguna secara real-time.
  • Payment Gateway Produksi: Integrasi resmi dengan penyedia layanan pembayaran seperti Midtrans atau Xendit untuk otomatisasi verifikasi transaksi melalui webhook.
  • WhatsApp & Email Gateway: Otomasi pengiriman kwitansi digital dan laporan berkala kemajuan belajar siswa langsung ke nomor WhatsApp donatur.
  • Role-Based Access Control (RBAC): Sistem autentikasi bertingkat antara donatur, verifikator keuangan, dan fasilitator lapangan.
